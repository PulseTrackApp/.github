# GymFlow

Application de suivi sportif : séances de course, de vélo et de marche avec tracé GPS, évolution physique, objectifs, défis et coach. Interface en français et en anglais, thèmes clair et sombre.

*English: a sports-tracking product made of a Flutter mobile app and a Spring Boot API.*

## Dépôts

- [mobile](https://github.com/PulseTrackApp/mobile) : application Flutter.
- [backend](https://github.com/PulseTrackApp/backend) : API Spring Boot et PostgreSQL.
